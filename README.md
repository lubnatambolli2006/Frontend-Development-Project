# Frontend Development Project

## Personal Portfolio Website

This project is a responsive personal portfolio website created using HTML, CSS, and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive navigation bar
- Home section
- About section
- Projects section
- Contact form
- JavaScript button interaction
- Form submission interaction
- Responsive design using CSS Grid and Media Queries
- Hover effects and smooth scrolling
